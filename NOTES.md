# NOTES — замечания по ручному E2E

Статус: все пункты исправлены в **v1.16.0** (подробности — в `CHANGELOG.md`).

1. ✅ **Аккордеоны и прокрутка** в карточке заявки сохраняются: после действий в секциях данные
   обновляются «тихо» (`refresh` вместо `load`) — страница не размонтируется.
2. ✅ **Календарь**: собственная реализация `DatePicker` — подсветка выбранного диапазона,
   блокировка дат вне `min`/`max`, навигация по месяцам, кнопки «Сегодня»/«Очистить».
   В плане мероприятий окончание не может быть раньше начала (подтягивается за началом
   и недоступно в календаре); в таблице даты показываются без времени.
3. ✅ **Бюджет**: колонка «Итого» (свои + запрашиваемые) и сводка по всей заявке;
   в форме — живой расчёт «кол-во × цена» и «итого по статье».
4. ✅ **Материалы**: длинные имена файлов обрезаются многоточием (полное имя — в подсказке),
   вёрстка не ломается.
5. ✅ **«Сохранить и выйти»** в модалке заявки; в режиме правки рядом есть «Сохранить»
   (сохраняет, не закрывая окно).
6. ✅ **`Input.fullWidth`** — поле на всю ширину контейнера; заголовок поста теперь широкий.
7. ✅ Иконки вынесены в `assets/icons/*.svg` (inline-фолбэк удалён); добавлены `user-minus`
   и `reset-password`.
8. ✅ У **бейджа-селекта** виден шеврон: причиной было то, что тон задавался шорткатом
   `background`, сбрасывавшим `background-image`.
9. ✅ **Поиск и фильтры** добавлены на страницы `/admin/users`, `/admin/applications`,
   `/admin/reviews`, `/admin/posts`, `/admin/tenders`, `/admin/directions`
   (`ListToolbar` + `SearchInput`; для больших списков фильтрация на backend).

Проверка итерации: `bun typecheck`, `bun run build`, прогон поиска/фильтров по тестовым
данным (`bun db:reset && bun seed`).
